# Archived: HERMES Boundary Lab

This folder holds an earlier project that used the HERMES name. It is **unrelated** to
the world model research described in the repository root.

Boundary Lab was a holography inspired neural memory experiment built around a bulk to
boundary to query architecture: a grid of cells is read by a learnable ring of boundary
slots through cross attention, and a query for a single cell must be answered by
attending only to that ring. The question it asked was an information layout one. If an
interior state can only be accessed through a smaller ring shaped exterior state, how
does the information end up arranged on that ring?

It is preserved here intact, with its original README, source, tests, Streamlit app and
Colab notebook. Nothing has been modified.

The HERMES name was later reused for the world model direction, which is what the
repository root now documents. The two share nothing beyond the name.
